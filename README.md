# Coffee Shop Landing Page

A simple, responsive, and elegant single-page website for a Coffee Shop. Built using HTML5, Bootstrap 3, and custom CSS, this landing page highlights various coffee varieties, daily specials, and engaging coffee quotes.

## 🚀 Features

* **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens using Bootstrap's grid system.
* **Navigation Bar:** A clean header navbar featuring smooth anchor links to transition between sections.
* **Hero Jumbotron:** A bold introduction area featuring a catchy coffee tagline.
* **Coffee Varieties Section:** Displays a curated list of standard coffee brews alongside classic quotes.
* **Specials Section:** Showcases specialty brewing styles and beverage choices (Espresso, French Press, etc.).
* **Icon Support:** Built-in integration with Font Awesome for iconography.

## 🛠️ Built With

* **HTML5:** Semantic markup structure.
* **Bootstrap v3.3.7:** Frontend framework for layout and responsiveness.
* **Font Awesome v4.7.0:** For vector icons and social logos.
* **jQuery & jQuery Easing:** For handling responsive navbar collapses and interactive animations.
* **Custom CSS & JavaScript:** For personalized layout tweaks (`css/main.css` and `js/main.js`).
